# SugarBuddy

SugarBuddy is a simple and friendly diabetes care companion built to help users track daily health habits, monitor blood sugar trends, stay hydrated, follow meal routines, and manage insulin reminders in one place.

## Overview

This project is a responsive web application designed for people managing diabetes and looking for a lightweight daily health tracker. It focuses on consistency, simple routines, and gentle reminders rather than complex clinical dashboards.

Users can:
- Create an account and log in
- Save personal health profile details
- Track blood sugar readings
- Log water intake
- Maintain meal plans
- Use a daily checklist
- Set insulin reminders
- Review calendar/history data
- Monitor progress over time

## Features

- User registration and login
- Personalized profile management
- Daily sugar tracking
- Water intake logging
- Meal planning and weekly routines
- Daily checklist for healthy habits
- Insulin reminder scheduling
- Notifications for routine reminders
- Activity history and calendar view
- Mobile-friendly responsive design

## Tech Stack

- HTML
- CSS
- JavaScript
- Local browser storage (localStorage)
